participant RS as Resolver (Exceptions)
participant QA as Auto QA Gate
participant EG as Ergo-Guard
participant SL as Slotter (Analytics)
participant TT as Tutor (Training)

Note over OP,WMS: 1) Task Intake & Setup
OP->>WMS: Login & fetch pick list
WMS-->>OP: Wave, SKUs, priorities
OP->>PL: Request optimized route/batch
PL->>WMS: Get slot map & item locations
WMS-->>PL: Locations, constraints
PL-->>OP: Route plan + batch (ETA/travel)
DI-->>OP: Work assignment balancing
EG-->>OP: Setup posture check (cart height)

Note over OP,GD: 2) Travel & Search Loop
loop For each line in route
  OP->>GD: Start navigation to next bin
  GD-->>OP: Turn-by-turn / aisle guidance
  OP->>VF: Scan shelf/label (or camera view)
  VF-->>OP: Match? (SKU/lot/expiry)
  alt Item not found / mismatch
    OP->>RS: Raise exception
    RS->>WMS: Query inventory deltas/nearby bins
    WMS-->>RS: Recent moves / substitutes
    RS-->>OP: Suggest alternate bin/substitute
  end
  EG-->>OP: Micro nudge (reduce reach/neck flexion)
  OP->>WMS: Confirm pick (qty/tote)
end

Note over OP,QA: 3) Handover & Quality
OP->>QA: Push tote through gate (in-motion)
QA-->>OP: Pass/Fail (weight/image check)
OP->>WMS: Close order & stage for packing

Note over SL,TT: 4) Learning & Improvement
WMS->>SL: Send traces (paths, errors, heatmap)
SL-->>WMS: Slotting recommendations
SL-->>OP: “Move look-alikes apart; heavy to mid-shelf”
WMS->>TT: Picker metrics (accuracy, posture flags)
TT-->>OP: Micro-coaching & progress feedback

3) Optional: PlantUML (text only)

@startuml
actor Operator as OP
participant "WMS" as WMS
participant "Planner" as PL
participant "Dispatcher" as DI
participant "Guide" as GD
participant "Verifier" as VF
participant "Resolver" as RS
participant "Auto QA Gate" as QA
participant "Ergo-Guard" as EG
participant "Slotter" as SL
participant "Tutor" as TT

== Task Intake & Setup ==
OP -> WMS : Login & fetch pick list
WMS --> OP : Wave, SKUs, priorities
OP -> PL : Request optimized route/batch
PL -> WMS : Get map & item locs
WMS --> PL : Locations, constraints
PL --> OP : Route plan
DI --> OP : Work assignment
EG --> OP : Setup posture check

== Travel & Search Loop ==
loop For each line
  OP -> GD : Navigate to next bin
  GD --> OP : Turn-by-turn
  OP -> VF : Scan/verify item
  alt Not found/mismatch
    OP -> RS : Raise exception
    RS -> WMS : Inventory delta query
    WMS --> RS : Deltas/nearby bins
    RS --> OP : Alternate bin/substitute
  end
  EG --> OP : Micro nudge
  OP -> WMS : Confirm pick
end

== Handover & QA ==
OP -> QA : In-motion check
QA --> OP : Pass/Fail
OP -> WMS : Close order & stage

== Learning & Improvement ==
WMS -> SL : Traces
SL --> WMS : Slotting recs
SL --> OP : Move look-alikes apart
WMS -> TT : Picker metrics
TT --> OP : Micro-coaching
@enduml

How to use

  • Copy the Mermaid blocks into docs, GitHub markdown, Notion, or MkDocs to render diagrams instantly.
  • Tune lifelines/steps to your site (e.g., drop agents you don’t pilot in phase 1).
  • For web apps, keep this HTML as a starting point and programmatically replace the Mermaid source with your runtime model.
